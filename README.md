# Sponsor Pro Dz AI Manager — Website

This repository contains the public information pages for the app:
- `index.html` — homepage
- `privacy-policy.html` — privacy policy
- `data-deletion.html` — user data deletion instructions
- `terms.html` — terms of service
- `app-icon.svg` — editable vector icon concept

## Publish with GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then Save.
4. Wait for deployment.

Expected URLs:
- https://cheetaah0.github.io/sponsor-pro-dz-ai-manager/
- https://cheetaah0.github.io/sponsor-pro-dz-ai-manager/privacy-policy.html
- https://cheetaah0.github.io/sponsor-pro-dz-ai-manager/data-deletion.html
- https://cheetaah0.github.io/sponsor-pro-dz-ai-manager/terms.html

## Important before submitting to Meta
These are starter policy templates. Confirm that every statement matches the app's actual data flows, AI providers, storage, retention, and deletion process. Do not claim that data is deleted unless you actually complete deletion. Monitor the contact email and fulfill verified requests. Keep secrets and access tokens out of this public repository.

The SVG is a vector concept, not the required 1024×1024 PNG app icon. Export it as a 1024×1024 PNG before uploading it to Meta.
